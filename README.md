# Каталог книг

Учебный проект на Python и Django.

## Описание проекта

Проект представляет собой сайт "Каталог книг".

На сайте можно:

- просматривать список книг;
- открывать подробную информацию о книге;
- добавлять новую книгу;
- редактировать данные книги;
- удалять книгу.

Для хранения данных используется база данных SQLite.

## Используемые технологии

- Python
- Django
- SQLite
- HTML
- CSS
